Data audit in your browser

Drop the CSV and Excel files a client sent and get a first-day audit: what each file holds, what is wrong with it in plain language, how the files connect, and which metrics the data can support. It is the browser version of DataIntake, with the same checks and the same wording.

Your files stay on this computer

The audit runs inside this page. Once the page has loaded it makes no network requests: nothing is uploaded, there are no analytics and no tracking. The page's Content Security Policy stops it from connecting to any other site, and your browser's network tab will show nothing being sent.
